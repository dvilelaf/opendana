This is the SDL2 shared library shipped in the package as bin/SDL2.dll,
cross-compiled with MinGW-w64 from the SDL 2.32.10 source tree at the revision
above (SDL_GetRevision: SDL-release-2.32.10-0-g5d24957). opendana.exe loads it from
its own directory and it can be replaced by an ABI-compatible build; see
RELINK.txt and sources/relink-materials.tar.xz. The small SDL2main entry
point of the same build (libSDL2main.a: src/main/windows/SDL_windows_main.c,
same Zlib licence) is linked statically into opendana.exe.

Third-party code compiled into the same DLL (Sun/fdlibm, HIDAPI, yuv2rgb,
imKStoUCS and Khronos headers) is covered by the separate SDL2-embedded
notice; MinGW-w64 runtime members linked into it by the separate
mingw-w64-runtime notice.

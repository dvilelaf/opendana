This is the SDL2 shared library shipped in the package as
lib/libSDL2-2.0.so.0 (SONAME libSDL2-2.0.so.0). It is built from the SDL
2.32.10 source tree at the revision above. The application links it through
RUNPATH $ORIGIN/../lib and it can be replaced by an ABI-compatible build; see
RELINK.txt and sources/relink-materials.tar.xz.

Third-party code compiled into the same shared library (Sun/fdlibm, HIDAPI,
yuv2rgb, imKStoUCS, edid-parse, Wayland protocol XML and Khronos headers) is
covered by the separate SDL2-embedded notice.

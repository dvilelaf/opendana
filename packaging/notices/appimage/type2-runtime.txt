The AppImage Type-2 runtime: the small static executable at the start of the
AppImage file that mounts the embedded SquashFS image (or extracts it) and runs
AppRun. It is built by this project from the source at the revision above with
packaging/appimage-runtime/build.sh (statically linked, reproducible). The
runtime statically links the components listed in the notices of libfuse,
squashfuse, musl, zstd, zlib and mimalloc. Copyright (c) 2004-23 probonopd and
the AppImage contributors.

The runtime also contains the C start-up objects and support routines of GCC
14.2.0 (Alpine 14.2.0-r4: crtbeginS.o, crtendS.o, libgcc), which are covered by
the GCC Runtime Library Exception, version 3.1: it allows the combined binary to
be distributed under the terms of its other components. They are not modified.

Zstandard 1.5.6 (libzstd), statically linked into the AppImage runtime (to
read zstd-compressed images). Zstandard is dual-licensed under BSD-3-Clause and
GPL-2.0; this project elects the BSD license. Copyright Meta Platforms, Inc.
and affiliates.

The zstd source in the licence bundle (sources/zstd.tar.xz) and in the runtime
source archive is the upstream 1.5.6 release with two changes needed by the
audit gates: the directory tests/ (test inputs and four symlinks; nothing in it
is compiled into the runtime) is left out, and the directory build/ (CMake,
Meson and Visual Studio files, not used by the runtime build) is renamed
build-files/. lib/, the only part compiled, is untouched; the pristine upstream
tarball is the one named in sources.lock of the repository.
